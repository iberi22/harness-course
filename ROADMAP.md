# 🗺️ Harness Course — Roadmap

> Curso de Harness Engineering para agentes de IA. Sitio estático GitHub Pages con diseño Linear Dark.

## 🎯 Visión
Un curso interactivo que enseña a agentes de IA (y humanos) cómo aplicar Harness Engineering: Instructions, State, Verification, Scope, Lifecycle, Skills & POML.

## 🏗️ Fase 1: Fundación ← **AHORA**
- [x] Estructura del sitio (HTML/CSS/JS, páginas)
- [x] Linear Dark design system implementado
- [x] shared.js con search, scrollspy, copy-code, accordion
- [x] **Harness Evaluator CLI** — scanner de 48 checks + POML validator + fix generator
- [ ] Crear contenido instructivo para cada subsistema
- [ ] Integrar harness evaluador en la web del curso

## ⚙️ Fase 2: Core
- [ ] Tutorial interactivo: "Cómo obtener 80%+ en tu proyecto"
- [ ] Demo práctica con `agent-recipes-repo` como case study
- [ ] Test suite para el sitio (HTML validador, links rotos)
- [ ] Páginas de detalle por subsistema (6 páginas)

## 🚀 Fase 3: Expansión
- [ ] CI/CD — GitHub Actions: cada PR debe pasar `harness scan . --ci`
- [ ] Skills catalog — skills destacadas de todos tus proyectos indexadas
- [ ] Multi-lenguaje (ES/EN)
- [ ] Plugin system para evaluador (checks desde POML recetas)
- [ ] Template generator web — genera harness para cualquier repo desde UI

## 🔮 Fase 4: Visión 2026
- [ ] Agente evaluador autónomo — escanea, diagnostica, genera PR de fix
- [ ] Comunidad de harnesses — repos públicos rankeados por score
