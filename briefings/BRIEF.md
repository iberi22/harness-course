# BRIEF.md — Harness Course

## Propósito del Proyecto
Enseñar Harness Engineering a agentes de IA mediante un sitio web estático (HTML/CSS/JS) con contenido práctico, ejemplos y un evaluador automatizado.

## Audiencia
- Agentes de IA (Claude, GPT, Gemini, etc.) que necesitan aprender a configurar su propio harness
- Humanos que quieren entender cómo crear entornos de trabajo óptimos para agentes

## Stack Técnico
- Frontend: HTML5 + CSS3 vanilla + JavaScript vanilla
- Design System: Linear Dark
- Hosting: GitHub Pages
- Evaluador: `harness` CLI (Python) — 48 checks en 6 subsistemas

## Estado Actual
- Score: 88.2% 🟢 EXCELENTE
- El curso tiene 13 páginas HTML con contenido completo
- El evaluador está pip-installable y funcionando

## Concepto Clave
Harness Engineering = Instrucciones + Estado + Verificación + Scope + Lifecycle + Skills/POML.
Un buen harness permite que cualquier agente de IA llegue y sea productivo en minutos.
