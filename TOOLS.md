# 🛠️ Tools — Harness Course

## Esenciales
| Tool | Propósito | Cómo se usa |
|---|---|---|
| `harness_evaluator.py` | Escanear, validar POML, generar fixes | `python3 scripts/harness_evaluator.py scan .` |
| `harness_scan.py` | Scan legacy (5 subsistemas) | `python3 scripts/harness_scan.py` |
| Git + GitHub Pages | Hosting y control de versiones | `git push` → `gh-pages` se despliega automáticamente |

## Opcionales
