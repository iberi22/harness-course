Harness Engineering

Awesome Harness Engineering Resources

A curated list of articles, playbooks, benchmarks, specifications, and open-source projects for harness engineering. These resources make agents more dependable in real workflows, especially long-running coding and research tasks.

A

Foundations

These five articles form the theoretical bedrock of harness engineering. Read them in this order.

📜

OpenAI: Harness Engineering

OpenAI's flagship field report on building a large application with Codex using architectural constraints, repo-local instructions, browser validation, and telemetry. The million-line experiment proves harness beats model upgrades.

📜

Anthropic: Effective Harnesses for Long-Running Agents

Anthropic's core article on initializer agents, feature lists, init.sh, self-verification, and handoff artifacts across many context windows. Essential for multi-session work.

📜

Anthropic: Harness Design for Long-Running Apps

Follow-up focused on improving long-running app generation with better task state and evaluator design. Covers context anxiety and premature convergence.

📜

Thoughtworks: Harness Engineering

Thoughtworks' framing of harness work into context engineering, architectural constraints, and "garbage collection" against entropy. Practical and grounded.

📜

HumanLayer: Skill Issue

A practical argument that weak results from coding agents are often harness problems rather than model problems. Essential mindset shift for practitioners.

B

Context, Memory & Working State

How to manage the context window as a working memory budget rather than a dumping ground.

🧠

Anthropic: Effective Context Engineering

Anthropic's guidance on managing the context window as a budget. Covers select, compress, isolate, and write operations with explicit cost management.

🧠

Manus: Context Engineering Lessons

Manus' detailed playbook on KV-cache locality, tool masking, filesystem memory, and keeping useful failures in-context. Production-grade insights.

🧠

Thoughtworks: Context Engineering for Coding Agents

Guidance on shaping the task environment so coding agents stay grounded and productive. Focus on reducing context drift.

🧠

HumanLayer: Advanced Context Engineering

Patterns for reducing context drift and making coding sessions easier to resume. Covers progressive disclosure in practice.

🧠

OpenHands: Context Condensation

Design for bounded conversation memory that preserves goals, progress, critical files, and failing tests while keeping long-running sessions efficient.

C

Constraints, Guardrails & Safe Autonomy

How to reduce approval friction without losing control through better sandboxing and policy design.

🛡️

Anthropic: Sandboxing Claude Code

Reducing approval friction without losing control through better sandboxing and policy design. Covers permission pipelines and auto-approve boundaries.

🛡️

Anthropic: Code Execution with MCP

Giving agents controlled execution power through explicit, inspectable tool boundaries. MCP as a fail-closed interface.

🛡️

Anthropic: Writing Effective Tools

Tool interfaces that are easier for models to call correctly and safely. Schema design, naming conventions, and error handling patterns.

🛡️

OpenHands: Mitigating Prompt Injection

Practical guide to confirmation mode, analyzers, sandboxing, and hard policies for reducing prompt-injection risk in autonomous coding agents.

D

Specs, Agent Files & Workflow Design

Standards and principles for structuring repo-local instructions and agent workflows.

📋

AGENTS.md Specification

A lightweight open format for repo-local instructions that tell agents how to work inside a codebase. The emerging standard for agent entry files.

📋

GitHub Spec Kit

GitHub's toolkit for spec-driven development. Useful when you want agents to execute against explicit product and engineering specs.

📋

HumanLayer: 12 Factor Agents

Operating principles for production agents: explicit prompts, state ownership, clean pause-resume behavior, and reproducible workflows.

📋

12-Factor AgentOps

An operations-oriented companion focused on context discipline, validation, and reproducible agent workflows.

E

Evals & Observability

If you can't measure harness quality, you can't improve it. These resources show how to evaluate agent behavior systematically.

📊

OpenAI: Testing Agent Skills with Evals

Concrete guide to turning agent traces into repeatable evals with JSONL logs and deterministic checks. The gold standard for agent evaluation.

📊

OpenHands: How to Evaluate Agent Skills

Hands-on playbook for measuring whether a skill actually helps using bounded tasks, deterministic verifiers, no-skill baselines, and trace review.

📊

Anthropic: Demystifying Evals

What to measure when agents have many possible trajectories to success or failure. Covers single-step, full-run, and multi-turn eval design.

📊

LangChain: Improving Deep Agents with Harness Engineering

Evidence that harness changes alone can significantly improve benchmark performance. Quantified improvements from specific harness interventions.

F

Benchmarks

These benchmarks stress context handling, tool calling, environment control, verification logic, and runtime scaffolding — making them ideal for comparing harness quality, not just model quality.

BenchmarkWhat It StressesWhy It Matters for Harness
SWE-bench Verified Real GitHub issues and tests Harness choices around retrieval, patching, and validation are highly visible
Terminal-Bench Terminal-native agents in shells and filesystems Directly compares coding-agent harnesses in verification-heavy environments
AppWorld Interactive coding agents in controllable app world State-based and execution-based unit tests surface harness quality
OSWorld Real computer-use across Ubuntu, Windows, macOS Tests desktop and multimodal harnesses with execution-based evaluators
ClawBench Search, reasoning, coding, safety, multi-turn conversation Breadth of harness demands in a single suite
Agent Arena ELO-style head-to-head agent battles Compares harness-level choices across categories
G

Runtimes, Harnesses & Reference Implementations

Open-source projects and frameworks that embody harness engineering principles.

⚙️

SWE-agent

A mature research coding agent that makes the harness, prompt, tools, and environment design directly inspectable. Excellent reference for tool registry patterns.

⚙️

deepagents (LangChain)

Building deeper, longer-running agents with middleware and harness patterns. Includes multi-agent coordination examples.

⚙️

AgentKit (Inngest)

TypeScript toolkit for building durable, workflow-aware agents on top of event-driven infrastructure. Lifecycle management built-in.

⚙️

Harbor

A generalized harness for evaluating and improving agents at scale, released alongside Terminal-Bench 2.0.

⚙️

Harness Evolver

Claude Code plugin that autonomously evolves LLM agent harnesses using multi-agent proposers, LangSmith-backed evaluation, and git worktree isolation.

⚙️

browser-use/browser-harness

A thin CDP-based browser harness that lets agents extend helper functions during execution. Useful for inspecting self-healing web-task workflows.
